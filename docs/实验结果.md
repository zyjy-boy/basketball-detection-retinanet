# 实验结果

## 一、模型训练结果

### 1.1 训练过程

训练设置：
- 优化器：AdamW（weight_decay=0.0005）
- 学习率：初始1e-4，余弦退火调度（T_max=50）
- 训练轮数：50 epochs
- 早停机制：验证集mAP连续5个epoch不提升则停止

损失变化：
- 总损失下降：**94.6%**
- 分类损失下降：**21.7%**
- 回归损失下降：**60.2%**

### 1.2 最终模型性能（合并测试集）

| 指标 | 数值 |
|------|------|
| AP@0.5 | **0.9002** |
| P@0.3 | **0.9375** |
| R@0.3 | **0.8936** |
| F1@0.3 | **0.9150** |

### 1.3 消融实验对比

| 实验 | 数据扩充 | 训练优化 | AP@0.5 | 提升 |

## 二、跨场景验证结果

### 2.1 各场景性能

| 场景 | 测试帧数 | AP@0.5 | 特点 |
|------|----------|--------|------|
| 明亮 | ~2000 | 0.9091 | 效果最好，无误检 |
| 近景 | ~1500 | 0.8961 | 均衡，偶有遮挡漏检 |
| 暗光 | ~1800 | 0.8182 | 受光照影响，召回率下降 |
| 远景 | ~1200 | 0.7081 | 小目标检测仍有提升空间 |

### 2.2 场景分析

**明亮场景**：
- 优势：光照充足，篮球纹理清晰
- 结果：mAP最高，无漏检和误检

**近景场景**：
- 优势：篮球占比大，特征丰富
- 问题：球员遮挡导致部分漏检

**暗光场景**：
- 问题：光照不足导致细节丢失
- 改进：可增加暗光数据增强

**远景场景**：
- 问题：篮球像素占比低（<1%）
- 改进：需采用小目标检测优化策略

## 六、结论

1. **检测性能**：模型在合并测试集上达到AP@0.5=0.9002，满足应用需求
2. **场景泛化**：明亮和近景场景表现优异，暗光和远景仍有提升空间
3. **轨迹分析**：SORT方法精度更高（NTE=0.102），适合精细轨迹分析；插值方法覆盖率更高，适合事件检测
4. **实时性**：31.76 FPS满足实时检测需求
