# 数据集说明

## 数据集来源

本项目数据集由以下公开数据集和自采数据整合而成：

### 1. Basketball Detection（Roboflow Universe）
- **原始数量**：2127张图片
- **有效样本**：约1280张
- **特点**：职业篮球比赛场景，涵盖近景、远景等拍摄角度
- **格式**：YOLO格式标注

### 2. Basketball Players
- **特点**：包含篮球和球员标注
- **用途**：提取篮球标注用于训练

### 3. SportsMOT
- **特点**：多目标跟踪数据集
- **用途**：筛选清晰篮球帧用于训练

### 4. 自采视频帧
- **来源**：自行采集的篮球比赛视频
- **特点**：补充特定场景数据

## 数据清洗流程

### 1. 类别筛选
- 仅保留篮球类别标注（类别ID=0）
- 去除其他运动目标标注

### 2. 格式转换
- 统一转换为YOLO格式：
  ```
  类别ID 中心点x 中心点y 宽度 高度
  ```
- 所有坐标归一化到0-1范围

### 3. 无效样本删除
删除以下无效样本：
- 无篮球标注的图片
- 坐标值超出0-1范围的标注
- 宽高为非正数的标注
- 图像质量过低的样本

**共删除无效样本约847张**

## 场景分布

数据集覆盖四种典型场景：

| 场景 | 特点 | 难度 |
|------|------|------|
| **明亮** | 光照充足，对比度高 | ⭐ |
| **暗光** | 光线不足，细节丢失 | ⭐⭐⭐ |
| **近景** | 篮球占比大，特征明显 | ⭐⭐ |
| **远景** | 篮球占比小，像素低 | ⭐⭐⭐⭐⭐ |

## 数据增强

训练时采用的数据增强策略：
- 随机翻转（水平/垂直）
- 随机旋转
- 随机缩放
- 颜色抖动（亮度、对比度、饱和度）
- Mosaic增强

## 输入尺寸

所有样本输入模型前统一调整为 **640×640像素**。
